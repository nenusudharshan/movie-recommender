# Movie Recommendation System

This project implements a **content-based movie recommendation system** using Python.

## Description
- Recommends movies based on similarity between movie features
- Uses cosine similarity for recommendation
- Focuses on content-based filtering approach

## Technologies Used
- Python
- Pandas
- Scikit-learn

## Concepts Covered
- Data preprocessing
- Feature extraction
- Cosine similarity
- Recommendation systems

## Usage
Run the notebook/script to generate movie recommendations based on input preferences.
